# Playwright Automation Scripts

Web automation scripts using [Playwright](https://playwright.dev/python/) for browser automation.

## 📂 Scripts

| Script | Description |
|--------|-------------|
| `cricket_scorecard_screenshot.py` | Captures cricket scorecard screenshots |
| `playwright_full_web_extract.py` | Full webpage content extraction |
| `playwright_key_functions.py` | Common Playwright helper functions |
| `playwright_web_extract.py` | Basic web content extraction |
| `search_t20_score.py` | Searches and extracts T20 cricket scores |

## 🚀 Setup

1. **Install Playwright**:
   ```bash
   pip install playwright
   playwright install
   ```

2. **Run a script**:
   ```bash
   python scripts/playwright_web_extract.py
   ```

## 📦 Dependencies

- `playwright` - Browser automation library
- Python 3.8+

## 💡 Features

- Headless and headed browser modes
- Screenshot capture
- Web scraping and data extraction
- Cross-browser support (Chromium, Firefox, WebKit)
