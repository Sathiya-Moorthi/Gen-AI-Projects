# Selenium Automation Scripts

Web automation scripts using [Selenium WebDriver](https://www.selenium.dev/).

## 📂 Scripts

| Script | Description |
|--------|-------------|
| `selenium_components.py` | Common Selenium components and helpers |
| `selenium_test_for_sauce_demo.py` | End-to-end test for Sauce Demo website |

## 🚀 Setup

1. **Install Selenium**:
   ```bash
   pip install selenium webdriver-manager
   ```

2. **Run a script**:
   ```bash
   python scripts/selenium_test_for_sauce_demo.py
   ```

## 📦 Dependencies

- `selenium` - Browser automation framework
- `webdriver-manager` - Automatic driver management
- Python 3.8+

## 💡 Features

- Cross-browser testing (Chrome, Firefox, Edge)
- Automatic WebDriver management
- Page Object Model patterns
- Test automation examples
