# RTCFR Prompting

RTCFR (Role, Task, Context, Format, Rules) prompting methodology templates.

## 💡 What is RTCFR?

RTCFR is a structured prompting framework:

- **R**ole: Define who the AI should act as
- **T**ask: Specify what needs to be done
- **C**ontext: Provide background information
- **F**ormat: Describe the expected output format
- **R**ules: Set constraints and guidelines

## 📂 Contents

This folder contains templates and examples using the RTCFR methodology.

## 🎯 When to Use

- Complex tasks requiring specific expertise
- Tasks needing structured outputs
- Situations requiring clear constraints
- Multi-step workflows

## 📚 Example

```
Role: Senior Python Developer
Task: Review this code for security vulnerabilities
Context: This is a Flask API handling user authentication
Format: Return findings as a numbered list with severity ratings
Rules: Focus on OWASP top 10, be concise, suggest fixes
```
