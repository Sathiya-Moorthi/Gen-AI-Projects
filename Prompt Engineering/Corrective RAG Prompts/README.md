# Corrective RAG Prompts

Prompts designed for Corrective RAG (CRAG) systems that evaluate and correct retrieval quality.

## 📂 Contents

| File | Description |
|------|-------------|
| `Corrective RAG Evaluation Engine Prompt.json` | JSON prompt for evaluating RAG responses |
| `Corrective RAG general prompt.txt` | General-purpose CRAG prompt template |
| `Assignment/` | Practice assignments for CRAG implementation |

## 💡 Usage

These prompts help build RAG systems that:
- Evaluate retrieval relevance
- Trigger web search fallbacks when retrieval is poor
- Improve answer quality through self-correction
