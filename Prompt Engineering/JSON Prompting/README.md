# JSON Prompting

Templates and examples for structured JSON output prompting with LLMs.

## 📂 Contents

| File | Description |
|------|-------------|
| `Structured JSON Prompt for Image Templates.json` | Prompt for generating image template configurations |
| `got season 8 script.txt` | Sample text for testing JSON extraction |
| `prompts/` | Additional JSON prompt templates |
| `output files/` | Sample outputs |

## 💡 Usage

JSON prompting ensures LLMs return structured, parseable data. Use these templates when you need:
- Consistent output formats
- Machine-readable responses
- Schema-validated data

## 📝 Best Practices

1. Define the exact JSON schema you expect
2. Provide examples in the prompt
3. Use explicit field descriptions
4. Request only necessary fields
