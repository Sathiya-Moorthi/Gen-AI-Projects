# Prompt Engineering

A curated collection of prompts for various LLMs and use cases.

## 📂 Categories
- **JSON Prompting**: Templates for structured JSON outputs.
- **Prompt Battle**: Comparative prompts for testing model performance.
- **Role-Based Prompts**: Prompts for specific roles (e.g., Python Developer, Data Engineer).
- **Corrective RAG**: Prompts for handling retrieval failures.

## 💡 Usage
Browse the `.txt` and `.json` files to find templates relevant to your needs.
