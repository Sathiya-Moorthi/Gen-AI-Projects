# Streamlit Scripts

Interactive web applications built with Streamlit.

## 📂 Applications

| Script | Description |
|--------|-------------|
| `basic_calculator_dashboard.py` | Simple calculator with Streamlit UI |
| `personal_expense_tracker.py` | Full expense tracking application |
| `test_streamlit.py` | Streamlit testing script |

## 🚀 Running

```bash
# Run the expense tracker
streamlit run personal_expense_tracker.py

# Run the calculator
streamlit run basic_calculator_dashboard.py
```

## 📦 Dependencies

```bash
pip install streamlit pandas
```

## 💡 Features

- **Expense Tracker**: Track income/expenses, categories, visualizations
- **Calculator**: Interactive calculator with clean UI
