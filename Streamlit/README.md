# Streamlit Applications

Interactive web applications built with [Streamlit](https://streamlit.io/).

## 📂 Structure
- **scripts**: Main application scripts.
- **output files**: Generated files.

## 🚀 Running an App
1.  **Install Streamlit**:
    ```bash
    pip install streamlit
    ```
2.  **Run**:
    ```bash
    streamlit run scripts/your_app.py
    ```
