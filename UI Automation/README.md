# UI Automation

This folder contains scripts for automating desktop UI tasks using tools like PyAutoGUI.

## 📂 Files
- `app.py`: Main application entry point.
- `notepad_automation.py`: Specific script for automating Notepad interactions.
- `test_api.py`: API testing script.
- `venv/`: Virtual environment (excluded from git).

## 🚀 Setup

1.  **Create Virtual Environment** (if not using the existing one):
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

2.  **Install Dependencies**:
    ```bash
    pip install flask pyautogui
    # Add other dependencies as needed
    ```

3.  **Run Automation**:
    ```bash
    python app.py
    ```
