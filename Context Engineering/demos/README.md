# Context Engineering Demos

Interactive demonstrations of context engineering techniques.

## 📂 Demo Scripts

| Script | Technique | Description |
|--------|-----------|-------------|
| `1_context_write.py` | WRITE | Context creation and token tracking |
| `2_context_select.py` | SELECT | Selective context passing |
| `3_context_compress.py` | COMPRESS | Context summarization |
| `4_context_isolate.py` | ISOLATE | Context isolation between tasks |

## 🚀 Running Demos

```bash
# Run individual demos
python demos/1_context_write.py
python demos/2_context_select.py
python demos/3_context_compress.py
python demos/4_context_isolate.py
```

## 💡 Learning Objectives

Each demo teaches a key context engineering skill:

1. **WRITE**: Understand how context grows and impacts token usage
2. **SELECT**: Filter relevant messages to reduce noise
3. **COMPRESS**: Summarize long conversations to fit token limits
4. **ISOLATE**: Prevent context leakage between unrelated tasks
