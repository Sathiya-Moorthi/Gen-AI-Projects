# Hugging Face Scripts

Jupyter notebooks demonstrating Hugging Face Transformers usage.

## 📂 Notebooks

| Notebook | Description |
|----------|-------------|
| `pulling_gpt_model_from_hugging_face.ipynb` | Download and use GPT models from HF Hub |
| `text_to_speech.ipynb` | Text-to-speech using HF models |

## 🚀 Setup

```bash
pip install transformers torch jupyter
```

## 💡 Usage

1. Open Jupyter:
   ```bash
   jupyter notebook
   ```
2. Navigate to the desired notebook
3. Run cells sequentially

## ⚠️ Notes

- Some models require significant RAM/VRAM
- GPU recommended for faster inference
- HuggingFace account may be required for some models
