# Python Challenge Days

A 15-day Python coding challenge to strengthen programming skills through daily practice.

## 📅 Challenge Structure

| Day | Focus Area |
|-----|------------|
| Day 1 | Fundamentals (Coconut Farmer Registration App) |
| Day 2 | Data Structures |
| Day 3 | Control Flow |
| Day 4 | Functions |
| Day 5 | File Handling |
| Day 6 | Error Handling |
| Day 7 | OOP Basics |
| Day 8 | Advanced Topics |

## 📂 Structure

```
python_challange_days/
└── scripts/
    ├── Day 1/
    │   └── Coconut Farmer Registration Application/
    ├── Day 2/
    ├── Day 3/
    ...
    └── Day 8/
```

## 🚀 Getting Started

1. Navigate to a day's folder:
   ```bash
   cd scripts/Day\ 1
   ```

2. Run the challenge script:
   ```bash
   python solution.py
   ```
