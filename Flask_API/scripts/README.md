# Flask API Scripts

Flask application examples demonstrating REST API development.

## 📂 Scripts

| Script | Description |
|--------|-------------|
| `basic_calculator_app.py` | Simple calculator REST API |
| `flask_math_operation_app.py` | Extended math operations API |
| `flask_structure.py` | Flask project structure example |

## 🚀 Running

```bash
# Run the calculator API
python basic_calculator_app.py

# Access at http://localhost:5000
```

## 📦 Dependencies

```bash
pip install flask
```

## 💡 API Examples

```bash
# Basic calculator
curl http://localhost:5000/add?a=5&b=3
# Response: {"result": 8}
```
