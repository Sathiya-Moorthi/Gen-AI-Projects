# Flask API Projects

Simple Flask applications and API examples.

## 📂 Files
- `basic_calculator_app.py`: A basic calculator API.
- `flask_math_operation_app.py`: API for performing math operations.
- `flask_structure.py`: Example of Flask project structure.

## 🚀 Running the Apps

1.  **Install Flask**:
    ```bash
    pip install flask
    ```

2.  **Run an App**:
    ```bash
    python basic_calculator_app.py
    ```
