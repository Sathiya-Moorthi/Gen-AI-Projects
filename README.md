## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Sathiya-Moorthi/Gen-AI-Projects.git
   cd Gen-AI-Projects
   ```

2. **Navigate to a project**:
   Each folder contains its own `README.md` with specific requirements and instructions.
   
   ```bash
   cd LangChain
   # Follow instructions in LangChain/README.md
   ```

3. **Set up environment** (recommended):
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   # source venv/bin/activate  # macOS/Linux
   ```
