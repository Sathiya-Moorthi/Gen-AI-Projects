# Gen AI Projects & Automation

This repository contains a collection of projects, scripts, and experiments related to Generative AI, Machine Learning, and Automation.

## 📂 Project Structure

## 📂 Project Structure

- **AutoGen**: Agents and multi-agent workflows using Microsoft AutoGen.
- **Flask_API**: API implementations and simple apps using Flask.
- **GraphRAG**: Graph-based Retrieval-Augmented Generation experiments.
- **Hugging_Face**: Projects leveraging the Hugging Face ecosystem.
- **KT**: Knowledge Transfer and presentation materials (includes ESMS).
- **Knowledge Graph RAG**: RAG implementation combined with Knowledge Graphs.
- **LangChain**: Workflows and applications built using LangChain.
- **Livekit**: Voice and video agent experiments (ensure secrets are secure).
- **Prompt Engineering**: Collection of prompts for various roles and tasks.
- **Python**: Miscellaneous Python scripts and challenges.
- **RAG**: Retrieval-Augmented Generation mechanisms and fallbacks.
- **RPA_Automation**: Automation scripts using Playwright, PyAutoGUI, and Selenium.
- **Streamlit**: Interactive web applications.
- **UI Automation**: Desktop automation tools (includes notepad automation).
- **Context Engineering**: Structured context engineering projects.
- **github_automation**: Scripts for automating GitHub interactions.
- **n8n automation**: Workflows and scripts for n8n automations.
- **python_challange_days**: Solutions for a 15-day Python coding challenge.
- **resume_comparison_tool**: Tool to compare resumes against job descriptions.

## 🚀 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Sathiya-Moorthi/Gen-AI-Projects.git
    ```
2.  **Navigate to a project**:
    Each folder contains its own specific requirements. Check the `README.md` within each subdirectory for detailed instructions.
    
    Example:
    ```bash
    cd "UI Automation"
    # Follow instructions in UI Automation/README.md
    ```
