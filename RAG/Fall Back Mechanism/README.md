# Fall Back Mechanism

Agentic RAG implementation with intelligent fallback strategies.

## 📂 Contents

| File | Description |
|------|-------------|
| `Agentic_RAG_Chatbot.py` | Main agentic RAG chatbot with fallback logic |
| `requirements.txt` | Python dependencies |

## 💡 Purpose

This module demonstrates how to build RAG systems that gracefully handle retrieval failures by:

1. Evaluating retrieval relevance
2. Triggering alternative search strategies
3. Combining multiple data sources
4. Improving answer reliability

## 🚀 Usage

```bash
pip install -r requirements.txt
python Agentic_RAG_Chatbot.py
```
