# GitHub Automation

Scripts for automating GitHub interactions.

## 📂 Scripts
- `git_automation.py`: Automate git commands.
- `push_to_github.py`: Helper script for pushing changes.
- `pushing_changes_from_local_repo_to_github_repo.py`: Script to handle local to remote pushes.

## 🚀 Usage
Configure your git credentials before running these scripts to avoid authentication errors.
