# n8n Projects

Complete n8n automation projects with multiple workflows and integrations.

## 📂 Workflows

| Workflow | Description |
|----------|-------------|
| `Automated Customer Emails.json` | Automated email responses for customers |
| `Support Request Notifications.json` | Slack/Telegram notifications for support tickets |
| `Design Request Automation.json` | Automates design request handling |
| `AI Agent using Ollama.json` | Local AI agent using Ollama |
| `DB_AI_AGENT.json` | Database-connected AI agent |
| `RAG AI Agent 2.0.json` | Advanced RAG-based AI agent |
| `Telegram AI Agent.json` | Telegram bot with AI capabilities |
| `Voice AI Agent - Jarvis.json` | Voice-enabled AI assistant |
| `Personal Assistant MCP server.json` | MCP server for personal assistant |
| `UI_Automation.json` | UI automation workflows |

## 🚀 Usage

1. Open your n8n instance
2. Go to **Workflows** > **Import from File**
3. Select the desired `.json` file
4. Configure credentials (API keys, tokens)
5. Activate the workflow

## ⚙️ Configuration

Most workflows require:
- API keys (OpenAI, Telegram, Slack, etc.)
- Webhook URLs
- Database connections (if applicable)

See individual workflow comments for specific requirements.
