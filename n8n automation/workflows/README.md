# n8n Workflow Templates

Learning and template workflows for n8n automation.

## 📂 Workflows

### Learning Workflows
| Workflow | Description |
|----------|-------------|
| `my first workflow.json` | Basic n8n workflow introduction |
| `my_first_scheduled_workflow.json` | Scheduled/cron-based workflow |
| `learning_trigger_nodes.json` | Various trigger node examples |
| `learning_webhook_node.json` | Webhook configuration examples |
| `learning_HTTP_node.json` | HTTP request node usage |
| `learning_code_node.json` | JavaScript code node examples |
| `data_flow_workflow.json` | Data transformation patterns |

### Production Templates
| Workflow | Description |
|----------|-------------|
| `Design Request Automation.json` | Design request handling template |
| `Support Request Notifications.json` | Support ticket notification template |
| `UI_Automation.json` | UI automation starter template |

## 🚀 Usage

1. Import into n8n: **Workflows** > **Import from File**
2. Review and customize nodes
3. Add your credentials
4. Test and activate

## 📚 Learning Path

1. Start with `my first workflow.json`
2. Learn triggers with `learning_trigger_nodes.json`
3. Master webhooks with `learning_webhook_node.json`
4. Add code with `learning_code_node.json`
5. Build production workflows!
